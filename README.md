# Vibe Coding met Claude — Prompts

Alle prompts uit het boek **"Vibe Coding met Claude: Van Idee naar App — Zonder Programmeren"** van Jean-Marc Zohlandt.

## Over

Deze pagina bevat de 60 prompts die in het boek worden gebruikt, klaar om te kopiëren en te plakken in Claude Code. Zo hoef je ze niet over te typen.

## Gebruik

Open `index.html` in je browser, of bezoek de live versie op GitHub Pages.

## Licentie

De prompts zijn onderdeel van het boek en vallen onder het auteursrecht van Jean-Marc Zohlandt. Ze worden hier aangeboden als hulpmiddel voor lezers van het boek.
